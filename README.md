## 🚕 3D 體驗怎麼玩

1. **任務 1：開往松山機場**　從敦化北路出發（離航廈約 500 公尺），開進航廈前的金色光圈。
2. **時光機啟動**　鏡頭繞著松機轉一圈，跑道消失，中央公園、AI 產業聚落與生活聚落一棟棟長出來。
3. **任務 2：探索 2033**　依序通過金色光圈：中央公園、AI 產業聚落、生活聚落、XY 軸捷運、跨河廊道、570 公頃都更。
4. **自由探索**　隨時切換 2026 ⇄ 2033、空拍、夜晚、導覽動畫。

### 🏁 2033 外送王（限時外送賽）

開著小黃在 2033 年的園區裡依序送 5 單，越快越好。總榜比 5 單全送完的時間，另外每一單都有自己的任務榜：這單進前 10 名就會暫停計時，讓你馬上登錄，或繼續送、最後一起登錄。登錄時像早期大型電玩一樣輸入 3 個英文字母，再把挑戰連結分享出去。

- 直接開賽：<https://ai2033.taipei/3d/?race>；分享出去的連結會帶上成績（`?race&vs=ABC.83450`），朋友開場就看到要挑戰的時間
- 路線：🥛 鮮奶 → 國際永續生活聚落、🍱 雞腿便當 → AI 產業聚落、🧋 珍珠奶茶 → 中央公園、🍍 鳳梨酥 → XY 軸捷運松機站、🍗 鹹酥雞 → 基隆河岸，全程約 3.3 公里
- 比賽中不能空拍、切年份、看導覽或瞬移回道路
- 排行榜：全台共用（Supabase），伺服器會逐點檢查路線；連不上時先存在玩家自己的裝置（見 [`tools/leaderboard/`](tools/leaderboard/)）
- 不用玩也能看榜：<https://ai2033.taipei/rank/>
- 分享卡：每筆成績的分享連結都有自己的預覽圖（名字、時間、名次），由 [`og/`](og/) 的小型 Vercel 服務產生

## 🧱 怎麼做的

- **真實街廓**：OpenStreetMap 臺灣圖資（Geofabrik），以 `osmium` 擷取臺北範圍，`tools/build/build_city.py` 轉成約 6 萬棟建築、道路、河川、捷運與地標的精簡 JSON（`3d/data/city.json`）。
- **園區配置**：依新聞稿文字，在機場與鄰近營區範圍上切出北側 110 公頃中央公園、南側 100 公頃 AI 產業聚落與 90 公頃生活聚落（**示意**，非正式設計圖）。
- **3D**：three.js r160（`vendor/three/`，無打包工具）；instanced mesh、shader 窗光與日夜、成長動畫、UnrealBloom、陰影、小地圖；手機自動降畫質。
- **網站**：純 HTML／CSS／JS，字級三段可調、深色高對比、行動優先。
- **逐字稿**：`tools/build/build_transcript.py` 由市府新聞稿與媒體答問整理；有音檔時可用 Whisper 重新轉寫（見下方）。
- **簡報**：`tools/build/deck.js`（pptxgenjs）產生 PPTX，LibreOffice 轉 PDF；`tools/build/slides_page.py` 產生線上翻閱頁。
- **素材**：`render.mjs`（3D 靜態圖）、`screenshots.mjs`（README 截圖）、`cards.mjs`（社群預覽圖與片頭片尾）、`record_demo.mjs`＋`make_demo.sh`（以虛擬時鐘逐格錄製示範影片）。

## 🎙️ 影片逐字聽打版（Whisper）

文字整理頁目前是**市府新聞稿全文**，加上媒體報導整理的答問重點。可用以下方式處理有權使用的影音；Whisper 結果仍需人工校對後才能稱為完整逐字稿：

1. 本機處理：把影音放進已忽略的 `research/youtube/input/`，執行 `bash tools/fetch/youtube.sh`，再執行 `python tools/fetch/transcribe.py /tmp/yt/audio16k.wav` 及 `python tools/build/build_transcript.py`。只提交校對過的文字結果。
2. 雲端處理：在 Actions → fetch-transcript → Run workflow，填入有權使用、可直接下載的 HTTPS 影音網址，手動啟動工作流程。

來源必須是你有權取得與使用的影音；不要將登入 cookies、API 密鑰或原始人聲檔提交到公開倉庫。
